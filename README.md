Каталог фильмов с Кинопоиска

Программа подгружает данные с https://kinopoiskapiunofficial.tech и выдает списком фильмы из топ-250. Можно почитать на отдельном экране краткую информацию о фильме и добавить в избранное (в отдельное окно). Есть настройки темы (день/ночь) и управление списком фильмов.


SwiftUI, Observation

Интеграция API и Сетевой слой: URLSession: Нативный сетевой стек на базе Async/Await 


База данных и Хранение: 
CoreData (Локальная БД): Создана сущность FavoriteMovie с атрибутами для хранения всех параметров фильма, включая кастомный приоритет (priority). Написан потокобезопасный CoreDataService (Singleton) для сохранения, чтения, проверки статуса (isFavorite) и удаления данных. 
UserDefaults (через @AppStorage): Системное постоянное хранилище настроек. Используется для мгновенной записи и чтения конфигурации приложения (выбранная тема, масштаб сетки) с сохранением состояния после перезапуска.
Дисковый кэш (FileManager): Написан сервис ImageCacheService, который перехватывает URL картинок, сохраняет графические файлы (JPEG) в системную папку Caches устройства и считывает их оттуда без повторных запросов в сеть.


Архитектура: MVVM
- Model (Слой данных): Абсолютно «чистый» Swift-код (Decodable). Полностью отделен от UI-фреймворков (никакого SwiftUI или UIKit внутри моделей).
- View (Слой интерфейса): Пассивные декларативные экраны, которые занимаются только отрисовкой и передачей действий пользователя.
- ViewModel (Бизнес-логика): Хранит состояние экранов и готовит данные для верстки (например, через вычисляемые свойства).


Ключевые архитектурные фичи:
- Dependency Inversion: Сетевой слой закрыт протоколом NetworkServiceProtocol. Интернет сервис на данный момент подменен Mock-сервисом в HomeViewModel. 
- Дата-центричная навигация: Вместо UIKit-координаторов навигация построена на базе современного NavigationStack, управляемого типами данных через .navigationDestination(for: Movie.self).


Микрофичи и Пользовательский интерфейс (UI/UX):
- Адаптивная сетка (1х1, 2х2, 3х3): Сетка каталога на главном экране динамически перестраивается из настроек с использованием анимации .spring().
- Умная пагинация и Поиск: Бесконечный скролл автоматически подгружает новые страницы. Написана защита от дубликатов, что предотвращает крэши SwiftUI. Реализован сброс поиска с возвращением к популярным фильмам при очистке строки.
- Immersive Header (Эффект погружения): Размытый постер во весь экран на экране информации о фильме. Контент лежит на градиентной подложке с эффектом матового стекла (.ultraThinMaterial) и плавно идет наверх, создавая полутемный контрастный экран при скролле.
- Динамические 10 звёзд: Написан компонент RatingStarsView, который делит рейтинг на 10 частей, рассчитывает и отображает целые, пустые и закрашенные ровно наполовину звёздочки (star.leadinghalf.filled).
- Скрывающийся TabBar: При переходе на экран деталей нижняя панель вкладок бесшовно скрывается, расширяя полезную площадь экрана, и плавно возвращается при выходе назад.
- Кастомный View.if() модификатор: Утилитное расширение для SwiftUI, позволяющее накладывать визуальные эффекты от состояния (CachedAsyncImage).
- Управление темами: Реализована изоляция тем. Пользователь может переключать тему (Светлая / Тёмная / Системная) для основного и избранного экрана.
- Мерцающий Skeleton (Shimmer): Вместо системного колесика загрузки написана маска на движущемся линейном градиенте. Во время ожидания ответа сети экран заполняется красивыми «дышащими» серыми заглушками по форме будущих ячеек.
- Логика приоритетов: В Избранном пользователь может выставить фильм как Важный (Низкий, Средний, Высокий приоритет). Система использует двухуровневую сортировку: сначала жестко закрепляет карточки по приоритетам (с цветовыми индикаторами-иконками), а уже внутри этих групп ранжирует их по рейтингу Кинопоиска.
